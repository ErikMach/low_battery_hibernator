# Low Battery Hibernator

This application will run quietly in the background, hibernating your computer if the battery gets too low. Saves your work!!

## Installation

Grab the binary from the latest release!
Or, clone the repo and build it yourself. Note that the threshold in the code is 65% battery... you might want to change that.

Also, it's helpful to add it to your "start-up apps" -- that way it's always got your back.

## Features

 - Event-driven (subscribes to system broadcast message)
 - Uses a message window for low memory
 - Typical memory usage: 380kB
 - Does nothing else!
